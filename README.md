📄 Descrição do entregável

Aplicação web desenvolvida em React para consultar repositórios do GitHub utilizando a GitHub API.

💻 Sobre o projeto

Projeto desenvolvido durante meus estudos em React com o objetivo de praticar o consumo de APIs e, principalmente, aprender a utilizar Styled Components para estilizar componentes da aplicação.

A aplicação permite pesquisar repositórios do GitHub utilizando o padrão:

usuário/repositório

Por exemplo:

facebook/react

Após adicionar o repositório, é possível visualizar suas informações e consultar suas issues.

## 🚀 Como utilizar

A aplicação está disponível online e pode ser acessada diretamente através do link:

🔗 **[Acessar o projeto](https://repo-swart-theta.vercel.app/)**

### Adicionando um repositório

Na tela inicial, utilize o campo **"Adicionar Repositórios"** para informar o repositório desejado.

O repositório deve seguir o padrão:

```text
usuário/repositório
```

Exemplo:

```text
facebook/react
```

Depois, clique no botão **"+"** para adicionar o repositório.

### Consultando um repositório

Após adicionar o repositório, ele aparecerá na lista de **"Meus Repositórios"**.

Clique no ícone de menu do repositório para acessar seus detalhes.

Na página do repositório serão apresentadas suas informações e as issues disponíveis.

### Filtrando issues

Na página do repositório, é possível utilizar os filtros:

* **Todas** → exibe todas as issues;
* **Abertas** → exibe apenas as issues abertas;
* **Fechadas** → exibe apenas as issues fechadas.

Também é possível navegar entre as páginas para consultar outras issues do repositório.
